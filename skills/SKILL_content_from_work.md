# SKILL: Content-From-Work (Transformar Trabalho Real em LinkedIn + X + TikTok)

## Princípio
**Zero invenção de conteúdo genérico. Zero Workslop.** Todo post nasce de um artefato real: commit, bug resolvido, benchmark na RX 7800 XT, arquitetura desenhada ou aula dos 45 artigos curados.

## Checklist de Compliance (OBRIGATÓRIO ANTES DE ESCREVER)
- [ ] Nenhum nome de cliente, tabela, volume real, query ou print interno do Grupo Permaneo aparece no texto.
- [ ] O foco é o **padrão técnico/arquitetural** ou o **dado público/próprio**.

## Pipeline 1 -> 3 (Saída Obrigatória)

Dado 1 artefato real (diff, arquitetura, benchmark ou experimento):
1. **LinkedIn (Post/Artigo):**
   - Linha 1 (Gancho): problema real + resultado/lição concreta (sem "Hoje quero refletir sobre...").
   - Corpo: contexto real -> decisão técnica + trade-off -> arquitetura/código/números -> lição de negócio.
   - Fechamento: **CTA binário fechado** (ex: "1 ou 2 nos comentários").
2. **X / Twitter (Thread 6–9 tweets):**
   - Tweet 1: gancho polarizador ou dado concreto + promessa de valor.
   - Tweets 2–7: 1 ideia por tweet, listas curtas, zero enrolação.
   - Tweet final: resumo + CTA binário + link do repo público `PUB-*` quando houver.
3. **TikTok / Reels (Roteiro 60–75s):**
   - `00–04s`: gancho visual/verbal de choque ou curiosidade real.
   - `04–55s`: 3 blocos objetivos (Problema -> Solução/Setup -> Trade-off real).
   - `55–70s`: CTA de palavra-chave única nos comentários.

## Trava de Qualidade
- Se o rascunho não tiver pelo menos **1 número, comando, peça de hardware, trade-off ou erro real**, rejeite como *Workslop* e reescreva.
